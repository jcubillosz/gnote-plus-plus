1.3.1

2026-10-06

  • English interface: on Macs set to English the app showed up in Spanish, because a formatting error in the translations file made macOS discard it entirely. It now follows the system language.

1.3.0

2026-10-06

  • Mermaid diagrams in the Markdown preview (flowchart, sequence, class, state, Gantt, pie, mind map and more), with a templates menu to get started. They render separately, without giving the preview JavaScript, and can be saved as PNG or SVG or copied as an image (also by right-clicking the diagram).
  • Markdown: its own formatting bar above the tabs; GitHub alerts (> [!NOTE], [!WARNING]…); task checkboxes you tick with a click in the preview; Enter continues lists; format and align tables (⌥⌘T); paste or drag images (outside ones are copied to images/ next to the document); document outline in the sidebar.
  • Notepad++ features: bookmarks and code folding, change history in the margin, brace and tag matching, highlighting of the selected word, multi-cursor and column editing, autocompletion in code, auto-closing of brackets and quotes, line operations, comment toggling (⌘K), zoom and line-ending conversion.
  • Minimap of the document to the right of the editor (⌃⌘M).
  • Find in files across the open folder, and a function list in the sidebar.
  • Open files reload when another program changes them; saving warns if the file changed on disk.
  • File tree: move files and folders by dragging or with "Move to…".
  • Tabs: arrows and a menu to reach tabs that don't fit in the window.
  • Markdown printing and PDF: lines are no longer repeated across pages, and the printer's paper size is used (File ▸ Page Setup…).
  • Fixes a crash when opening with word wrap on and the spell checker enabled.

1.2.0

2026-09-27

  • Edit lock per document (padlock in the toolbar, ⌘⇧L): navy background, truly read-only, still lets you select and copy. Useful for sensitive content you don't want to change by accident.
  • Spell checker in Spanish and English (off by default, Edit ▸ Spelling): wavy underline, suggestions, learn and ignore words from the context menu. In code it only checks comments and strings.
  • Markdown: three view modes (editor / split / preview only) and double-click in the preview to jump to the source line. Code blocks with a language label and syntax highlighting in the preview and in print. Print text about 30% smaller.
  • File tree: create files and folders and rename them right there (extension included), refreshing automatically when the disk changes.
  • Drag files and folders from Finder to open them; the session (tabs, cursor, folder) is restored when the app relaunches.
  • The "unsaved" dot no longer appears when opening a file without changing it, and each tab remembers its cursor position and selection.

1.1.0

2026-09-09

  • Syntax highlighting: fixes a bug that left the editor uncolored (plain black text) in any build made with swift build outside the packaged .app — it affected every language except Markdown.
  • Print / export Markdown to PDF, rewritten: it now uses the real WebKit engine instead of a limited importer, so tables, headings and code blocks look the same as in the preview. Real pagination (breaks between paragraphs and rows, not mid-line) and 2 cm page margins.
  • Blockquotes (> text) styled as notes: green border and text on a light green background.

1.0

2026-09-07

  • First public release: Scintilla editor with tabs, file tree, light and dark themes, syntax highlighting for Notepad++ languages, encoding and line-ending detection, find and replace with regular expressions, and a GitHub-compatible Markdown preview.
