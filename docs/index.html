The Markdown editor for people who also write code.

GNote++ is a free, open-source Markdown and code editor for macOS. Write prompts, docs and web content with a live preview and Mermaid diagrams, on top of the editing engine and syntax highlighting of Notepad++.

Download for Mac

Version 1.3.0. Requires macOS 13 or later on Apple silicon. Signed and notarized by Apple.

Markdown source on the left, live preview on the right, outline in the sidebar.

Who it's for

Prompt engineers

System prompts, prompt libraries, CLAUDE.md and AGENTS.md files are Markdown. See them rendered as you write, jump between sections from the outline, sketch agent flows in Mermaid, and lock a finished prompt so it can't change by accident.

Web and content editors

Draft blog posts and pages for Markdown-based sites. Paste or drag images and they're saved next to the file; tables line up with one shortcut; the preview matches GitHub's rendering.

Technical writers

READMEs, runbooks and docs with GitHub alerts, task lists and diagrams. Export diagrams as PNG or SVG, and print or save the whole document as PDF.

Developers

The same file can be Python, YAML or SQL: every language Notepad++ highlights, regex search, find in files, multi-cursor editing and a minimap.

Markdown, done properly

  • Three views: editor, split, or preview only. Double-click the preview to jump to that line in the source.
  • GitHub Flavored Markdown: tables, task lists you can tick in the preview, alerts, strikethrough, autolinks.
  • Code blocks highlighted in the preview with the same themes as the editor.
  • Mermaid diagrams: flowcharts, sequence, class, state, Gantt, pie, mind maps. Start from templates; export as PNG or SVG.
  • Formatting toolbar, lists that continue on Enter, table formatting.
  • Outline of headings in the sidebar.
  • Print and PDF with proper page breaks.
  • Spell checker in English and Spanish.
  • Private by design: the preview runs no scripts and diagrams render offline.

And a full code editor

  • Syntax highlighting for every language Notepad++ supports, with its themes in light and dark mode.
  • Multi-cursor and column editing, autocompletion, brace and tag matching.
  • Bookmarks, code folding, change history, function list and a minimap.
  • Find and replace with regular expressions; find in files across a folder.
  • Encoding and line endings detected and kept on save.
  • Tabs, file tree, session restore, reload of files changed on disk.

Questions

Is it a good editor for AI prompts?
Yes. Prompts and agent instruction files are usually Markdown, and GNote++ previews them as you write, shows their structure and keeps everything on your Mac.
Is there a Notepad++ for Mac?
Notepad++ itself only runs on Windows. GNote++ brings its editing engine, language definitions and color themes to macOS as a native app.
Is it free?
Yes. Free and open source under the GPL-3.0 license.
Which Macs does it run on?
Macs with Apple silicon (M1 or later) running macOS 13 Ventura or later.
Is it affiliated with Notepad++?
No. GNote++ is an independent project based on Notepad++'s open-source code and is not endorsed by it.

Build from source

GNote++ is a Swift Package Manager project. Clone the whole repository, then:

cd mac/NppMacPOC
swift build
./scripts/make_app_bundle.sh
open .build/GNote++.app
